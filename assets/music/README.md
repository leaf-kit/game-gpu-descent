# GPU DESCENT — BGM 가사집 (Lyrics Book)

게임 **GPU 디센트: 실리콘 속으로**에 쓸 배경음악 가사입니다. 테마별로 묶었고, 각 곡은 게임의 특정 구간에서 재생되도록 설계했습니다.

**목적**: 반도체와 GPU를 이해하는 데 필요한 내용을 노래로 익히게 하는 것. 한국인이라면 누구나 알아들을 수 있는 말로 쓰되, 숫자와 사실은 조사 문서에서 확인된 값만 넣었습니다.

**표기 원칙**
- 가사 속 모든 수치는 `docs/research/01~07_*.md`의 1차 출처(NVIDIA 백서, 학술 논문, TSMC·ASML·SK하이닉스 공개 자료)에서 가져왔습니다. 곡마다 끝에 「가사 속 사실」 표로 근거를 답니다.
- 노래로 부르기 쉽도록 숫자는 한글로 풀어 적었습니다(예: 814 mm² → "팔백십사 제곱밀리").
- 확인되지 않은 수치는 가사에 넣지 않았습니다.

**사용법**
- 음원 파일을 `assets/music/`에 아래 「음원 파일」 이름 그대로 넣으면 게임이 자동으로 찾아 재생합니다.
- 화면·층이 바뀌면 그 구간의 곡으로 약 1초 크로스페이드됩니다. 우측 상단 플레이리스트 위젯에서 직접 고를 수도 있습니다.
- 아직 음원이 없는 곡(05 서른둘의 구령, 10 어텐션)은 같은 테마의 다른 곡으로 대체해 재생됩니다.
- 메인 테마 파일명은 `bgm.mp3`입니다. 이 파일이 없으면 배경음악 없이 효과음만 나옵니다.
