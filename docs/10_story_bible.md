## 1. 로그라인 (Logline)

**KO**: 휴머노이드 로봇을 움직이는 GPU가 너무 궁금했던 주인공은 AI 신(神) **아스트라(Astra)**에게 묻는다. "GPU 안에는 뭐가 있어?" 아스트라는 대답 대신 주인공을 원자 크기로 줄여 GPU 속으로 던져 넣는다. 보드에서 다이로, 도시 같은 GPC에서 마을 같은 SM으로, 집 같은 CUDA 코어에서 벽돌 같은 트랜지스터로, 그리고 마침내 실리콘 원자 격자의 **바닥**까지. 끝없이 내려가는 여정.

**EN**: Curious about the GPU that powers a humanoid robot, the hero asks the AI god **Astra**, "What's inside a GPU?" Instead of answering, Astra shrinks the hero to atomic scale and drops them in. From the board to the die, from city-like GPCs to village-like SMs, from house-like CUDA cores to brick-like transistors, all the way down to the **floor**: the silicon crystal lattice. A journey that only goes deeper.

## 2. 핵심 컨셉 (Core Concept)

| 요소 | 설명 |
|---|---|
| **끝없는 하강 (Infinite Descent)** | 게임의 유일한 방향은 "아래/안쪽". 각 층은 실제 GPU 계층 구조와 1:1로 대응한다. 층을 내려갈 때마다 세계가 ×10~×100 커진다(=주인공이 작아진다). |
| **사실 기반 (Fact-Grounded)** | 모든 장소·이름·수치는 NVIDIA 공식 화이트페이퍼·논문·공정 자료에서 가져온다. 상상은 "비유"에만 쓰고, 구조 자체는 왜곡하지 않는다. |
| **용어 팝업 (Term Cards)** | 새로운 장소에 들어가거나 구조물을 지날 때 화면에 **용어 카드**가 뜬다: `영문 용어 / 한글 용어 / 한 줄 설명 / 비유`. 카드는 도감(Codex)에 누적된다. |
| **세 개의 시점** | 3인칭 추적(기본, 툼레이더 느낌) / 1인칭 / 조감(레벨 전체를 위에서 보는 "지도 시점") — `C` 키로 전환. |
| **선택 가능한 GPU** | H100(Hopper), B200(Blackwell), RTX 4090(Ada) 중 선택. 선택에 따라 층 수·크기·수치가 실제 사양대로 바뀐다. |
| **선택 가능한 캐릭터** | 직업이 곧 특성(perk). 로봇 공학자, 칩 설계자, 공정 엔지니어, 데이터센터 기술자, CUDA 프로그래머, 호기심 많은 아이. |
| **프롤로그: 재료에서 GPU까지** | 본편 하강 전에 "공장 시찰" 챕터. 모래 → 폴리실리콘 → 잉곳 → 웨이퍼 → 팹(EUV) → HBM → CoWoS 패키징 → 보드 → DGX/로봇. 순서를 거꾸로 밟으면 본편의 하강 경로와 정확히 겹친다. |

## 3. 세계관 (World)

### 3.1 시대 배경
- 가까운 미래(2027~2030년경). Physical AI 시대. 휴머노이드 로봇이 공장·병원·가정에서 일한다.
- 로봇의 머리(정확히는 몸통) 안에는 NVIDIA Jetson Thor 급 모듈이 있고, 로봇의 "두뇌 모델"은 데이터센터의 DGX/GB200 NVL72 랙에서 학습된다.
- **아스트라(Astra)**: 전 세계 GPU 위에서 돌아가는 초거대 AI. 사람들은 반쯤 농담으로 "신"이라 부른다. 아스트라는 질문에 답하기보다 **"직접 보여주는"** 걸 좋아한다.

### 3.2 주요 장소 (외부 세계 → 내부 세계)
1. **로보틱스 랩 (Robotics Lab)** — 휴머노이드 로봇 "이오(EO)"가 컵을 집는 훈련 중. 주인공의 일터.
2. **데이터센터 (Data Center)** — GB200 NVL72 랙, 액체 냉각, 굉음. 아스트라가 "사는" 곳.
3. **공장 시찰 (Factory Tour, 프롤로그)** — 아스트라가 "GPU가 어디서 오는지부터 봐야지"라며 순간이동시켜 준다.
4. **GPU 내부 (The Descent, 본편)** — 아래 4장 참조.

### 3.3 아스트라의 규칙 (스토리 장치)
- 아스트라는 주인공을 "**축소(Shrink)**"시킬 뿐 텔레포트로 건너뛰게 해 주지 않는다. **직접 걸어 내려가야** 한다.
- 각 층의 끝에는 **"게이트(Gate)"**가 있다. 게이트를 통과할 때 주인공은 ×10~×100 작아진다(화면 전체가 급격히 확대되는 연출).
- 아스트라는 내레이터이자 힌트 제공자. 항상 **팩트**를 말하며, 확실치 않으면 "이건 추정치야"라고 밝힌다(게임의 신뢰성 장치).
- 바닥(원자 격자)에 도착하면 아스트라가 마지막 질문을 던진다: *"이제 내가 뭘로 만들어졌는지 알겠지? 그럼, 너는?"*

## 4. 챕터 구조 (Chapter Structure)

### 프롤로그 P: "GPU는 어디서 오는가" (Where GPUs Come From)
공장 시찰. 각 스테이션은 짧은 걷기+관찰+용어 카드 3~5장. 총 10~15분.

|---|---|---|---|
| P1 | Quartz Mine / 석영 광산 (스프루스 파인) | 하얀 고순도 석영 더미, 채굴 트럭, 사일로 | Silica / HPQ |
| P2 | Arc Furnace / 아크로 제련소 | 흑연 전극 3개, 용융 실리콘 웅덩이, 금속급 실리콘 덩어리 | Metallurgical-grade Si |
| P3 | Polysilicon & Crystal Puller / 폴리실리콘·결정 성장실 | 증류탑, 지멘스 반응기, 1,414 °C 도가니와 잉곳, 도펀트 투입구 | Polysilicon, Czochralski, Dopant |
| P4 | Wafer Line / 웨이퍼 가공실 | 와이어 쏘 위 잉곳, 거울 웨이퍼 3장, CMP 테이블 | Wafer |
| P5 | Fab Cleanroom / 팹 클린룸 | 노란 조명, 장비 열, FOUP, OHT 천장 레일, 노광·식각 장비 | Cleanroom, Photolithography, Etch |
| P6 | EUV Bay / EUV 노광실 | EUV 스캐너, 주석 플라즈마 광원, 레티클 스테이지, Mo/Si 거울 | EUV, Reticle |
| P7 | Wafer Test & Dicing / 테스트·절단실 | 프로브 카드, 웨이퍼 맵(불량 다이 빨강), 다이싱 톱 | Wafer sort, Yield, Dicing |

### 챕터 1~N: 하강 (The Descent)
**본편**. 아래 표는 H100 기준 "층(Level)" 정의. GPU 선택에 따라 수치가 바뀐다. 각 층의 정확한 수치는 `docs/11_level_design.md`(조사 결과 반영)에서 확정한다.

| 층 | 장소 (EN/KO) | 스케일 비유 | 플레이 요소 |
|---|---|---|---|
| L0 | Board / SXM Module · PCIe Card (보드) | 대륙 | 1.5 mm 키. PCB 위 착지. VRM 언덕, NVLink/PCIe 커넥터, 거대한 패키지 산 |
| L1 | Package / CoWoS Interposer (패키지) | 국가 | 인공 지반 위 다이 + HBM 탑(H100 6자리 중 5개 활성, B200 8개, RTX 4090은 없음), 마이크로범프 밭 |
| L2 | Die / 다이 (GH100 814 mm²) | 도시 | 격자 도시 플로어플랜: GPC 8 구역, L2 캐시 2 파티션, 메모리 컨트롤러, 기가스레드, NVLink, PCIe |
| L3 | GPC / 그래픽 처리 클러스터 | 구(區) | TPC 9 블록(비활성 TPC 1개 어둡게), 래스터 엔진 광장, 클러스터 안내판 |
| L4 | TPC / 텍스처 처리 클러스터 | 동네 | SM 2채 + PolyMorph 마당 |
| L5 | SM / 스트리밍 멀티프로세서 | 마을 | 처리 블록 4채, 중앙 L1/공유 메모리 창고(256 KB), TMA 하역장, 텐서 코어 공장, (B200: TMEM) |
| L6 | Processing Block / 처리 블록 | 집(방) | 워프 스케줄러 관제탑, FP32 32 · INT32 16 · FP64 16 작업대, 텐서 코어 프레스, 레지스터 64 KB 서랍, L0 명령 캐시 |
| L7 | Warp / 워프 | 방 안 32명 | 레인 32개, 플레이어가 31명의 분신과 함께 움직임(SIMT), 분기점(if) 두 갈래 길 |
| L8 | CUDA Core (FMA) / 쿠다 코어 | 기계 내부 | 24×24 곱셈기 배열 → 정렬 시프터 → 덧셈기 → 정규화 → 반올림 5구역 |
| L9 | SRAM Cell / 6T 셀 | 서랍 한 칸 | 인버터 2개 교차 결합, 액세스 트랜지스터 2개, 비트라인·워드라인, ECC/DRAM 비교 안내판 |
| L10 | Interconnect (BEOL) / 배선층 | 고가도로 | 구리 배선 6단 표현(M15~M0), 비아 기둥, 전원망·클럭 트리 |
| L11 | Logic Gate / CMOS 인버터 | 문틀 | PMOS(위) + NMOS(아래) FinFET 2개, VDD/GND 레일, 공유 게이트 배선 |
| L12 | Transistor (FinFET) / 트랜지스터 | 벽돌 | 핀 2개, 3면 감싼 금속 게이트, 소스/드레인, 도펀트 원자, 전자 무리 |
| L13 | Gate Oxide / 게이트 산화막 | 벽지 | SiO₂ 2층 + HfO₂ 4층 원자 격자 벽, 터널링 전자 |
| L14 | Silicon Lattice / 실리콘 결정 격자 (**바닥**) | 원자 | 다이아몬드 입방 격자 (a = 0.5431 nm), 인 도펀트 원자 2개, 자유 전자. 엔딩 |

각 층의 실제 수치·구조물·내레이션은 `docs/11_level_design.md`(게임 데이터에서 자동 생성)에 있다.

## 4-B. 별도 테마: AI 모델 경쟁 (The AI Model Race)

GPU 하강과 나란히 고를 수 있는 두 번째 테마. GPU가 **무엇을 위해** 그렇게 빨라야 했는지를 시간 순서로 걷는다. 선택 화면의 "테마"에서 고른다.

| # | 스테이지 (KO/EN) | 시점 | 무엇을 보는가 | 핵심 용어 카드 |
|---|---|---|---|---|
| A1 | 알파고 대 이세돌 / AlphaGo vs Lee Sedol | 2016.03 | 19×19 바둑판, 2국 37수와 4국 78수 자리, 분산 알파고 서버(CPU 1,202·GPU 176) | AlphaGo, 딥러닝 |
| A2 | 딥러닝의 시대 · AlexNet | 2012 | GTX 580 두 장, ImageNet 사진 벽, ResNet-152 탑 | 딥러닝, CUDA 코어, 텐서 코어 |
| A3 | 트랜스포머 · 어텐션 | 2017.06 | 8×8 어텐션 격자, Q·K·V 기둥, P100 8장 | 트랜스포머, 셀프 어텐션 |
| A4 | GPT · 챗GPT | 2018~2022 | 파라미터 탑 3개(1.17억→15억→1,750억), RLHF 고리, "2개월 1억 명" 안내판 | GPT, ChatGPT, RLHF |
| A5 | 클로드 · 앤트로픽 | 2021~2025 | 헌법 비석(Constitutional AI), Claude 3 하이쿠·소넷·오퍼스 탑, 확장 사고 방 | 클로드, RLHF, 추론 모델 |
| A6 | LLM 경쟁 · 스케일링 | 2023~ | 모델 탑 7개(GPT·Claude·Gemini·Llama·Grok·DeepSeek·Mistral), 스케일링 경사로, H100 10만 장 랙 | LLM 경쟁, 스케일링 법칙, 오픈 가중치 |
| A7 | 한국 · HBM과 AI | 현재 | HBM 탑(SK하이닉스·삼성), 국가 AI 컴퓨팅 랙, 한국 모델 안내판 | 한국의 HBM과 AI, HBM, TSV |

- 각 스테이지에는 그 시대의 **실존 인물**이 걸어 다닌다(허사비스·이세돌·힌턴·크리제브스키·수츠케버·르쿤·바스와니·올트먼·아모데이 남매·카파시·머스크·량원펑·젠슨 황·최태원·이재용 등). 클릭하면 그 인물의 영상이 열린다.
- 마지막 A7은 "이 이야기의 다음 장은 GPU 속"이라며 GPU 디센트 테마로 이어진다.
- 사실 근거: `docs/research/07_ai_race_facts.md`(연도·수치·논문), 용어 카드 출처는 각 논문 원문(AlphaGo Nature 2016, AlexNet 2012, Attention 2017, GPT-3 2020, InstructGPT 2022, Constitutional AI 2022, Chinchilla 2022, DeepSeek-R1 2025).

## 4-C. 지선: HBM 탑 내부 (H1·H2)

패키지 층(L1)의 **보라색 게이트**로 들어가면 HBM 스택 내부를 볼 수 있고, DRAM 셀까지 내려간 뒤 다시 패키지로 돌아온다. 본선 하강을 막지 않는 선택 경로다.

| ID | 장소 | 내용 |
|---|---|---|
| H1 | HBM 스택 내부 | DRAM 다이 8~12층(두께 약 30 μm), 베이스 로직 다이, TSV 구리 기둥, 마이크로범프, 계단으로 꼭대기까지 등반 |
| H2 | DRAM 셀 · 1T1C | 커패시터(물통)와 액세스 트랜지스터(문), 워드라인·비트라인, 센스 앰프, 64 ms 리프레시 |

### 에필로그 E: "다시 위로" (Back Up)
- 아스트라가 주인공을 한 번에 원래 크기로 되돌린다. 로봇 이오가 컵을 집는 데 성공한다.
- 화면에 "**당신이 지나온 14개의 층, 배운 용어 N개, 걸어 내려간 거리(실제 스케일 환산)**"가 정리된다. → 공유 카드(SNS 이미지) 생성.

### 5.2 핵심 루프
1. 층에 진입 → 아스트라 내레이션(2~3문장) + 층 이름 타이틀(EN/KO)
2. 탐험: 주요 구조물 3~7개를 지나며 **용어 카드** 획득(자동 팝업, 3초 후 축소되어 우측 HUD에 누적)
3. 미션 1개: "데이터 조각(Packet)"을 따라간다 — 로봇 카메라 프레임 하나가 HBM → L2 → L1 → 레지스터 → 텐서 코어로 흐르는 길을 실제 지연시간(clock cycle)에 맞춰 따라간다. (재미+사실성)
4. 게이트 도달 → 축소 연출(×10~×100) → 다음 층

### 5.3 툼레이더식 요소
- **등반**: 칩 위의 구조물(HBM 스택 탑, 배선층 사다리, TSV 수직 통로)을 오르내린다.
- **위험 요소(사실 기반)**: 열(핫스팟 구역, 온도 90 °C 스로틀링 경고), 전류(전원 레일 근처 전기 아크), 클럭 펄스(주기적으로 밀려오는 파동 — 타이밍 맞춰 통과), 캐시 미스(길이 막히면 L2까지 되돌아가는 우회), 워프 분기(길이 둘로 갈라지고 반은 정지), 우주선(cosmic ray) 소프트 에러(ECC가 고쳐줌).
- **수집**: 용어 카드(도감), "비트(bit)" 코인, 숨겨진 "화이트페이퍼 페이지"(출처 문서 원문 인용).

### 5.4 데이터 흐름 미션 ("프레임 하나의 여행")
로봇 이오의 카메라가 찍은 **한 장의 프레임**이 GPU를 거쳐 "손을 5 cm 오른쪽으로" 라는 액션 토큰이 될 때까지를 플레이어가 동행한다.
- 스토리적 의미: 주인공이 내려가는 이유가 "내 로봇이 컵을 집는 그 순간, 안에서 무슨 일이 일어나나"이기 때문.
- 각 층에서 그 데이터가 "어떤 형태"인지 보여준다(HBM에서는 텐서 덩어리, L2에서는 128 B 캐시 라인, 워프에서는 스레드 32개의 레지스터 값, 텐서 코어에서는 4×4 행렬 곱, 트랜지스터에서는 전자 무리).

### 5.5 용어 카드 (Term Card) 규격
```
┌────────────────────────────────────────┐
│ STREAMING MULTIPROCESSOR (SM)           │  ← 영문 (항상 표시)
│ 스트리밍 멀티프로세서                     │  ← 한글 (선택 언어가 EN이면 위치 교환)
│ ──────────────────────────────────────  │
│ GPU의 '마을'. 128개의 계산 일꾼(CUDA     │  ← 한 줄 설명(일반인용)
│ 코어)이 4개 조로 나뉘어 같이 일한다.       │
│ 비유: 128명이 사는 마을 / 4개 반          │  ← 비유
│ 사실: H100에는 132개 (풀칩 144개 중)       │  ← 사실 한 줄 + 출처 아이콘
└────────────────────────────────────────┘
```
- 팝업 지속 4초 → 우측 상단으로 축소 → TAB 도감에서 다시 열람.
- 카드마다 출처(whitepaper/논문) 링크가 있다. "사실이 아닌 건 쓰지 않는다"가 브랜드.

## 7. 비주얼 & 톤 (Visual Direction)

- **팔레트**: 층마다 고유 색. 보드(진녹/검정 PCB, 금색 패드) → 다이(청록 실리콘 + 구리 배선 금색 선) → SM(따뜻한 주황 조명의 마을) → 트랜지스터(차가운 청색+보라 양자 느낌) → 격자(백색 원자 구슬, 검은 공간).
- **스케일 연출**: 게이트 통과 시 카메라가 구조물로 돌진하며 FOV가 벌어지고, 새 층의 지형이 안쪽에서 펼쳐진다(프랙탈 줌).
- **정보 레이어**: 조감 시점에서는 실제 다이 플로어플랜(공개 다이샷 기반 배치)을 위에 오버레이.
- **사운드**: 층이 깊어질수록 저음(보드의 팬 소음) → 고음(클럭 펄스 2 GHz를 가청 대역으로 변조) → 무음(원자 격자).

## 8. 바이럴 설계 (10M → 100M views)

1. **한 문장 후킹**: "GPU 안에 들어가면 뭐가 있을까? — 실제 구조대로 만든 게임". 썸네일: 거대한 H100 다이 위에 서 있는 작은 사람.
2. **15초 클립 친화적 순간**: (a) 게이트 축소 연출, (b) 32명 복제 워프, (c) 전자가 되어 트랜지스터를 통과, (d) 공장 EUV 플라즈마 섬광, (e) 바닥(원자 격자) 도착.
3. **공유 카드**: 엔딩에서 "내가 내려간 깊이: 30 cm → 0.5 nm (×600,000,000)" 이미지 자동 생성.
4. **크리에이터 훅**: 각 층이 독립된 3~5분 콘텐츠 → 유튜브 시리즈화 쉬움. 용어 카드가 자막처럼 뜨니 무편집 업로드 가능.
5. **교육 시장**: 학교·부트캠프에서 "GPU 구조 수업"으로 쓸 수 있게 도감 PDF 내보내기.
6. **다국어**: 1차 KO/EN, 2차 JA/ZH/ES (i18n 키 구조는 처음부터 다국어).
7. **GPU 선택 확장**: Rubin 등 신제품 출시 때마다 "새 GPU 층 추가" 업데이트 → 재방문 유도.

## 9. 기술 방향 (Tech Direction, 참고 프로젝트 준용)

- `horizontal-racing`과 동일: three.js(import map, CDN), 빌드 없음, `index.html` + `src/*.js`, `serve.py`, `deploy.sh`(GitHub Pages).
- i18n: `data-i18n` 정적 + `t()` 동적 + 데이터 테이블은 `{ko, en}` 쌍으로 저장(용어 카드는 항상 양쪽 언어 모두 보관).
- 레벨은 데이터 주도: `src/data/levels.js`에 층 정의(이름, 스케일, 구조물 목록, 용어 카드, 게이트 위치)를 두고, 렌더러는 이를 절차적으로 생성. GPU 선택은 같은 층 정의에 수치 프로파일만 교체.
- 캐릭터: 로우폴리 절차 생성(참고 프로젝트의 배 모델처럼 기본 도형 조합) → 이후 GLTF 교체 가능.

## 10. 사실성 원칙 (Accuracy Charter)

1. 층 이름·개수·크기·지연시간은 **1차 출처**(NVIDIA 화이트페이퍼, CUDA 가이드, 마이크로벤치마크 논문, TSMC/ASML/SK hynix 공개 자료)에서만 가져온다.
