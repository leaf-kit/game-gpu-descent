- **Thumbnail width caveat:** as of 2026-09 the Wikimedia thumbnail service only serves a fixed set of widths. Requests for `800px-` thumbnails returned HTTP 400, whereas `960px-` (the width the Commons API itself returns for `iiurlwidth=800`) returned 200. The file therefore uses `https://upload.wikimedia.org/wikipedia/commons/thumb/.../960px-...` (PNG renders for SVG sources). Files narrower than 960 px use the original `https://upload.wikimedia.org/wikipedia/commons/...` URL because bitmaps cannot be up-scaled by the thumbnailer. `thumb.wikimedia.org` serves the same paths; `upload.wikimedia.org` was kept per the spec.
- Rate limiting: `upload.wikimedia.org` returned 429 during a fast burst; all checks were re-run with a 1 s delay and all passed.
